# Запит із п’яти блоків: `registerParticipant` (Частина 1)

## 1. Роль
Ти — досвідчений розробник на JavaScript (Node.js, CommonJS), який пише чистий, надійний код із перевіркою граничних випадків.

## 2. Контекст (обов’язковий)
- Робочий проєкт — система реєстрації на події коледжу (`#src/store.js`).
- У `#src/store.js` уже описано типи `CollegeEvent`, `Participant`, `EventRegistry` і фабрику `createEventRegistry(event)`.
- Вимоги замовника зафіксовано в `#docs/customer-answers.md` (пункти 1–9, 13–14).

## 3. Завдання (обов’язкове)
Створи у файлі `src/registration.js` та експортуй у форматі CommonJS (`module.exports = { registerParticipant }`) функцію:
`registerParticipant(registry, participant, now = new Date())`

Логіка роботи:
1. Перевір час закриття реєстрації: момент `now`, що дорівнює або перевищує `registry.event.registrationClosesAt` (`>=`), вважається закритим — викинь `Error` з дослівним текстом `"Реєстрацію закрито"`.
2. Перевір електронну пошту (`participant.email`): прибери пробіли по краях і переведи в нижній регістр. Якщо пошта порожня, не містить `@`, перед `@` порожньо або після `@` немає крапки в домені — викинь `TypeError` з дослівним текстом `"Некоректна електронна пошта"`.
3. Перевір ПІБ (`participant.fullName`): прибери пробіли по краях. Якщо рядок порожній — викинь `TypeError` з дослівним текстом `"Вкажіть ПІБ"`.
4. Перевір дублікати за нормалізованою поштою в обох масивах (`registry.registered` і `registry.waitlist`). Якщо знайдено збіг — викинь `Error` з дослівним текстом `"Учасник уже зареєстрований"`.
5. Нормалізований об’єкт учасника (`email`, `fullName` і необов’язкове поле `group`, якщо задано) додай у `registry.registered`, якщо `registry.registered.length < registry.event.capacity`, та поверни `{ status: "registered" }`.
6. Якщо вільних місць немає — додай учасника в `registry.waitlist` та поверни `{ status: "waitlisted", position: registry.waitlist.length }`.

## 4. Обмеження
- Не змінюй `src/store.js` і файли в каталозі `test/`.
- Не використовуй сторонні бібліотеки (лише стандартний Node.js / JavaScript).
- Не додавай відправлення email-підтверджень та роботу з базою даних (дані лишаються у переданому `registry`).
- Тексти всіх повідомлень про помилки бери дослівно без перефразування.

## 5. Формат
Надай лише повний вміст файлу `src/registration.js` із JSDoc-коментарями українською та короткий перелік перевірених граничних випадків.
