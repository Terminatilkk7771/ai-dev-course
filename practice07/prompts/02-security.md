# Запит з оптикою безпеки (Завдання 4)

```text
Проаналізуй цей код як рецензент, що відповідає за безпеку.
Вимоги до API: [таблиця вимог з README.md]
Код: [# файл]

Перевір окремо:
1. Обробку вхідних даних від користувача.
2. Формування запитів до бази даних.
3. Перевірку автентифікації та прав доступу.
4. Зберігання паролів і секретів.
5. Обробку помилок і те, що потрапляє у відповідь користувачу.

Для кожної проблеми вкажи: рядок, суть, можливий наслідок, спосіб виправлення.

```

## Систематизовані знахідки по 4 модулях

### `src/students.js`
- **[Рядок 7, `listStudents`]** Off-by-one помилка: `start + PAGE_SIZE - 1` повертає 4 записи замість 5 (`README.md`).
- **[Рядок 13, `findByName`]** SQL-ін’єкція (OWASP A05): конкатенація `"'%" + name + "%'"` ламається на апострофі, дозволяє ін’єкції (`%' OR 1=1 --`) та не екранує символи `%` і `_` для `LIKE`.
- **[Рядок 25, `averageGrade`]** Ділення на `0`: при відсутності оцінок `0 / 0` дає `NaN` замість `null`.
- *(Хибне спрацювання)* Відсутня перевірка `id` у `getById`/`averageGrade`/`deleteStudent` — насправді валідацію виконує `validateId` у `src/app.js`.

### `src/app.js`
- **[Рядок 20, `/api/login`]** `req.body.login` без захисту від порожнього або не-JSON тіла запиту (кидає `TypeError` → 500 замість 401).
- **[Рядок 26, `/api/students`]** `Number(req.query.page) || 1` пропускає від’ємні числа (`?page=-1`), що зміщують зріз із кінця масиву.
- **[Рядки 42–43, `/api/students/:id/card`]** Stored XSS (OWASP A05): `s.name` та `s.group_name` вставляються у HTML без екранування, а при `avg === null` виводиться `NaN` замість «оцінок немає».
- **[Рядок 46, `DELETE /api/students/:id`]** Порушення контролю доступу (OWASP A01): `requireAuth` перевіряє лише токен, але не роль `teacher` (`student` може видалити будь-кого замість 403).
- **[Рядок 52, error handler]** Витік внутрішньої інформації: у 500-відповіді повертаються `err.message` і `err.stack`.
- *(Хибне спрацювання)* `GET /api/students` не вимагає токена — відповідає специфікації `README.md`.

### `src/auth.js`
- **[Рядок 5, `hashPassword`]** Криптографічний збій (OWASP A04): використано швидкий нестійкий MD5 без солі замість `crypto.scrypt` із випадковою сіллю.
- **[Рядки 18–26, `verifyToken`]** Слабкість розбору `split(".")` при крапках у логіні та перевірка `Authorization` без чіткої вимоги префікса `Bearer `.

### `src/config.js`
- **[Рядок 5, `TOKEN_SECRET`]** Секрет `"journal-secret-2026"` зашитий у відкритий код замість зчитування зі змінної середовища `process.env.TOKEN_SECRET`.
